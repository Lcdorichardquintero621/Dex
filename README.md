# Dex — escritorio para tu Android

## Compilar el APK (GitHub)
1. Crea un repositorio y sube todo el contenido de esta carpeta.
2. En la pestaña **Actions** se ejecuta "Compilar APK" (o ábrelo con *Run workflow*).
3. Descarga el artefacto **Dex-APK** → `app-debug.apk` e instálalo.

## Primer uso
1. Abre Dex → engranaje ⚙ → **Activar ventanas libres** y en Opciones de desarrollador activa:
   *Habilitar ventanas de forma libre* y *Forzar modo escritorio* (reinicia el teléfono).
2. ⚙ → **Usar Dex como pantalla de inicio**.
3. Conecta el monitor por USB-C/HDMI, o usa ⚙ → **Pantalla inalámbrica**.

## Atajos
- Tecla Windows/Meta: menú de inicio.
- Clic derecho en el escritorio: menú.
- Mantener pulsado (o clic largo) en un icono: fijar al dock, pantalla completa, info.
